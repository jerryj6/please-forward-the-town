# Design Research Dataroom 3 — Level-as-Sentence / Interest-Curve Pacing

Seeded sources: Stephen's Sausage Roll pacing analyses (increpare's
level ordering; the "hard levels before the easy ones" structure),
Arvi Teikari's and Lavelle's level-order design principles (levels as
one idea each; order as a sentence, not a ramp), puzzle-campaign
interest curves. Mapped onto PFT's 12-level arc.

## 1. Each level says ONE new thing (one-idea-per-level)

- **Source:** Lavelle's principle — a level teaches, explores, or
  resolves a single idea; difficulty is incidental to clarity. SSR's
  levels each introduce exactly one obstruction grammar.
- **PFT application:** the campaign is already authored this way —
  mailbox alone (02), one-boat juggling (02), deployed-address
  duality (03), vertical ordering (04), postal-as-transport (05),
  service-as-deliverable (06), movable address (07). Chapters 3–4
  combine rather than repeat. Verified: no level ships two new
  mechanics; PFT-11/12 combine only mechanics already taught.

## 2. Spikes are load-bearing, not accidental

- **Source:** SSR pacing analyses show difficulty spikes are placed
  deliberately — the hard level precedes relief so the insight lands.
  Interest curves are sawtooth, not monotone.
- **PFT application:** the move-depth curve is honest evidence: 9, 16,
  17, 18, 13, 17, 20, 21, 38, 28, 28, 44. pft-05 drops to 13 right
  after pft-04's 18 — a breather after a spike. pft-09's 38 is the
  campaign's hard spike; pft-10's 28 is relief-with-alternates before
  the 28/44 finale. The rung-gap pattern (no 10/18/39-move plans on
  01/03/09) means difficulty is quantized by topology — spikes are
  structural, not tuning artifacts.

## 3. Combos arrive only after every part is taught

- **Source:** SSR orders levels so a combination level follows all of
  its primitives; the parser never confronts an untaught element.
- **PFT application:** verified via coopNote/WA analysis — PFT-08
  combines bridge-teardown (03) + ferry (06) + capacity juggling (02);
  PFT-11/12 combine movable address (07) + postal (05) + service
  delivery (06) + teardown ordering (03). No prerequisite inversion
  exists in the 12-level order — the cardinal ordering graph is a DAG.

## 4. Exits and returns as rhythm (the finale earns its name)

- **Source:** interest-curve design uses callback peaks — a late level
  recontextualizes an early mechanic so the campaign feels composed.
- **PFT application:** PFT-12 "Everything Must Go" IS the callback —
  it reuses every mechanic (sign as movable infrastructure, postal
  wire, ferry freight, teardown order) so the finale is a recap at
  higher stakes. Plan A's "office first" vs B's "office last" gives the
  player the arc's central question one last time.

## 5. Multiplicity discipline

- **Source:** SSR lets alternates exist but curates which are
  advertised — a discovered alternate is treasure, a listed one is a
  spec.
- **PFT application:** solutionPolicy per level does exactly this:
  'hybrid' levels list the golden plans + tolerate alternates
  (enumerated: 5–24 plans/level, 1–6 distinct optimal strategies);
  'open' levels (08, 10, 12) advertise the space honestly. The
  documented-alternates section curates found solves (PFT-10 plan C)
  so they're treasure, not noise.
